# Speed Alert 🏂

スノーボードでキッカーに進入するとき、設定した目標スピードに近づくにつれてビープ音の間隔が
「ぴっ……ぴっ…ぴっ ぴっ ぴぴぴ ピーーー」と短くなっていくスピードアラームです。
イヤフォンを付けて滑れば、画面を見ずに耳だけでアプローチスピードを合わせられます。

スマホのブラウザで動く PWA です。アプリストア不要で、ホーム画面に追加すればアプリのように使えます。

## 使い方

1. HTTPS でホストしたページをスマホで開く（Geolocation API の制約で HTTPS 必須。GitHub Pages が手軽）
2. **目標スピード**（キッカーに合った進入速度）と**アラーム開始**（目標の何 km/h 手前から鳴らし始めるか）を設定
3. イヤフォンを付けて「スタート」→ 位置情報を許可
4. ポケットに入れて滑る（**画面は点けたまま**。アプリが画面ロックを自動で防ぎます）

- アラーム開始速度未満 … 無音
- 目標に近づく … ビープ間隔が 900ms → 110ms へ指数的に短縮、ピッチも上昇
- 目標以上 … 連続音（ピーーー）

家の中で音の感じを確かめたいときは「デモ」にチェックを入れてスライダーで速度を模擬できます。

## スピード計測の考え方

GPS の速度は「位置の差分」ではなく **ドップラーシフト由来の速度**（`coords.speed`）を第一候補に
使っています。これは移動中なら ±0.5〜1 km/h 程度と意外に高精度です。本当の課題は精度よりも
**更新頻度（約1Hz）と 1〜2 秒の遅延**なので、このアプリでは速度と加速度を平滑化しつつ、
最後のGPSフィックスから現在時刻まで**加速度で外挿**して遅延を補償しています。

`coords.speed` が取れない端末では位置差分（ハバーサイン距離 / Δt）にフォールバックし、
精度の悪いフィックス（±30m 超）は捨てています。

## 制約と注意

- **iOS Safari は画面が消えると GPS が止まります。** Wake Lock API で自動的に画面を点けたままにしますが、手動でロックしないでください。Android Chrome も同様に画面オン推奨です。
- スマホは体で電波を遮らない位置（ジャケットの胸ポケットなど、なるべく上側・外側）に入れると精度が上がります。
- GPS の1〜2秒遅延は外挿で補償していますが、急加速の立ち上がりでは実速度よりわずかに遅れて聞こえることがあります。目標速度を実際に飛びたい速度より 2〜3 km/h 低めに設定して数本流して調整するのがおすすめです。
- 音はメディア音量で鳴ります。滑走前に音量を確認してください。

## 開発

依存なしの静的ファイル 4 つだけです（`index.html` / `sw.js` / `manifest.webmanifest` / `icon.svg`）。
ローカル確認は `python3 -m http.server` などで OK（localhost は HTTPS 免除）。
